## Word 同文多窗

同一文档，多处对照。这个 Quicker 动作用于 Windows 桌面版 Microsoft Word：一键建立同一文档的多个视图，方便对照前文、修改长文或同时查看不同段落。

### 使用方法

先激活 Word 中的目标文档，再调出 Quicker 面板。

| 操作 | 效果 |
| --- | --- |
| 左键运行动作 | 不足两个窗口时补齐到两个，并左右排列 |
| 已有双窗时再次左键 | 保持两个窗口并重新排列，不会不断新增窗口 |
| 右键 → 自定义窗口总数 | 输入 1–12 的整数，回车后补齐并排列；数量包含原窗口 |
| Esc 或取消 | 不执行开窗 |
| 已有窗口多于输入数量 | 保留已有窗口，只重新排列 |

两窗左右排列，三窗及以上按网格排列。自定义数量成功使用后会在本机记住；左键始终以双窗为目标。小屏幕建议使用 2–4 个窗口，窗口过多时 Word 的最小窗口尺寸可能造成重叠。

### 原理与实现

动作先恢复调出 Quicker 面板前的活动窗口，再执行 C# 脚本，通过 Word COM 自动化操作当前文档的窗口集合。

- 新窗口是同一文档的另一个视图，文档内容共享，各窗口可以独立滚动。
- 只补齐缺少的窗口，避免重复点击后产生过多窗口。
- 按启动动作时 Word 所在显示器的可用桌面区域计算排列位置；只调整当前文档的窗口。
- 不创建文档副本，不主动保存或关闭文档，不上传文档内容。
- 仅在本机 `LocalAppData/Quicker/WordMultiWindow/count.txt` 记录上次输入的数量。

### 导入与适用范围

1. 下载上方的动作 JSON 文件。
2. 在 Quicker 面板空白格右键选择“导入动作”，选择该文件。
3. 打开一个空白 Word 文档，回到文档后调出 Quicker 面板进行测试。

JSON 是完整的动作导入包，包含模块步骤、嵌入的 C# 源码、名称、图标及右键参数。源码与说明用于维护，不需要分别导入。导入后，动作由 Quicker 保存，日常运行不需要再次读取下载的 JSON 文件。

适用于 Windows 桌面版 Microsoft Word，不适用于网页版 Word、WPS 或受保护视图。Word 弹出模态对话框时，先关闭对话框再运行。

### 已有验证记录

- C# 核心通过 .NET Framework 编译，JSON 通过 Quicker 1.45.5 动作类型校验。
- 排列算法通过 72 组测试，覆盖负坐标、奇数分辨率及 1–24 个窗口的几何布局；这不代表界面允许输入 24 个窗口。
- 已成功导入 Quicker，确认左键能够打开同一文档的双窗。
- 重复左键保持双窗符合设计。
- 四窗、取消输入、独立滚动和多文档隔离尚无单独的实测结果记录。

### 修改与备份

维护资料包中保留 `action/` 源码和导入文件、`docs/` 使用说明与发布记录、`tools/` 构建脚本与排列测试，以及 `rebuild.cmd` 和校验清单。

1. 修改前，备份整个维护目录。
2. 修改 `action/WordMultiWindow.cs`。
3. 在 Windows 下运行 `rebuild.cmd`，编译、测试并重新生成 JSON。工具按本机 Quicker 1.45.5 数据格式制作，需要 Windows PowerShell、.NET Framework 及 `C:/Program Files/Quicker`。
4. 备份 Quicker 中的现有动作，导入新 JSON，在空白文档中验证。
5. 确认功能后更新正式动作及原有分享，并同步说明和版本记录。

单独修改 `.cs` 不会自动更新导入 JSON、已安装动作或线上分享；重新生成工具也不会自动安装或发布。
